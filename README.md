# Airlines Management System

A simple web-based Airlines Management System frontend designed to manage and display airline operations through a dashboard.

## Features

- **Dashboard** — Overview of airline operations.
- **Arrivals** — View flight arrival information.
- **Departures** — View flight departure information.
- **Passengers** — Passenger management interface.
- **Jet Fuel** — Jet fuel details and cost calculation.
- **Runway Maintenance** — View runway maintenance information.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/Vaibhav-sri09/Airlines-Management-System.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No additional dependencies are required to run the frontend.
